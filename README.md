# Change Control Success Predictor 

This project uses Machine Learning to predict whether proposed process changes (like those in pharma or manufacturing) will succeed or fail before they are implemented. It includes a smart prediction system and an interactive, easy-to-use dashboard.

Key Features

• Realistic Predictions: The model only uses information available before a change starts. It ignores future data (like final closing times) to ensure the predictions are fair and accurate.
• Text Analysis: It reads through the written descriptions of proposed changes to spot hidden risks in the wording.
• Interactive Dashboard:
  a. Test One Change: Type in a single hypothetical change to get an instant success score.
  b. Test Multiple Changes: Upload a spreadsheet (CSV) of multiple proposed changes to instantly see them ranked from highest to lowest chance of success.
